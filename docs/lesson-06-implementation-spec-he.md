# שיעור 6 — עקרון אפנון FM ומשדר

## מימוש

- נגן השיעור משתמש במעטפת Lesson 4 עבור סטודנטים ומרצים, עם מצב תצוגה מקדימה, ניווט, outline, הערות מקומיות, הצגה ומשוב שקף.
- תוכן השקפים והזמנים נמצא במקור אמת יחיד: `src/components/lesson-06-data.ts`. יש 23 שקפי תוכן ומפריד הפסקה אחד.
- המערך המורחב מפרק את המעבר מתדר רגעי למופע באמצעות אינטגרציה, כולל הצבת `ωₘ=2πfₘ` והזיהוי `β=Δf/fₘ`. הוא כולל הסברים פיזיקליים, יחידות, בדיקות הבנה, אומדן קרסון, הוכחת הספק קבוע, שרשרת VCO/מכפיל/PA, ופתרון מספרי מלא המחולק לשלבים.
- המחשות אינטראקטיביות בנגן וב־HTML העצמאי: שינוי תנופת המידע והצגת הקשר ל־`Δf` תוך שמירת מעטפת FM; כוונון מתח הכניסה ב־VCO והמחשת הקשר לשיפוע `Kf`; שינוי `n` במכפיל והצגת `f꜀` ו־`Δf` מוכפלים בעוד `fₘ` נשאר קבוע.
- משך התכנון במימוש הוא 135 דקות, כולל הפסקה של 10 דקות. בקובץ התכנון שנמסר סכומי הביניים הסתיימו ב־150 דקות למרות הצהרה על 135; זמני ההוראה חולקו מחדש כדי להתאים למסגרת 135 הדקות.
- מפתחות הפידבק/מצב השיעור משתמשים ב־`lesson-06` ומזהי השקפים `lesson-06-fm-XX`.

## דיוק והנחות תוכן

- נוסחת קרסון מוצגת כאומדן מקורב לרוחב הפס המכיל בקירוב את רוב הספק אות FM סינוסואידלי. לא מוצגת הבטחת 98% מדויקת לכל אות.
- חסינות FM לרעש מנוסחת בזהירות: מגביל משרעת במקלט יכול להחליש רעש משרעת, אך רעש עדיין יכול להשפיע.
- הספק FM קבוע הוא תכונה של המודל האידאלי בעל המעטפת הקבועה. אין להסיק מכך לבדו נצילות כוללת של המשדר; הנצילות תלויה גם בדרגת ההספק ובמימושה.
- מכפיל התדר מתואר במודל שבו הוא מכפיל את `f_c`, את `Δf` ואת `β`, אך משאיר את `f_m` ללא שינוי. מימוש פיזי דורש סינון/בחירת הרמוניה, ופרטי התכן אינם נכללים בשיעור.
- הדוגמאות המספריות והייחוס לעמודי מקורות הועתקו מהתכנון שסיפק המשתמש. לא אומתו מול עותקים זמינים של הסילבוס, נוסחאון מה״ט או ספרי הלימוד.

## מצב בדיקה

`npm run export:lesson-06-html`, `npm run validate:lessons`, `npm run typecheck`, `npm run build` ו־`git diff --check` עברו. ה־HTML העצמאי עודכן עם אותם מחוונים וגרפים. בדיקה חזותית דרך הדפדפן האוטומטי לא התאפשרה: מדיניות הדפדפן חוסמת פתיחת כתובות `file://`; לא נעשה ניסיון לעקוף את החסימה. בדיקת ה־layout החזותית נשארת לא מאומתת.
