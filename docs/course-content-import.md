# הוספת חומרי קורס ל־Syllo

## מה חסר כרגע

כעת רשומים ב־Registry חומרי שיעורים 1–3. מערך השיעור והתרגול של שיעור 1 נשארים בקישורים החיצוניים שסופקו. ארבעת קובצי ה־HTML של שיעורים 2–3 הועתקו ל־`public/` ומאוחסנים יחד עם האפליקציה.

## מיקום קבצים

העתיקו את החומרים הקיימים אל:

`public/course/communication-systems/`

לדוגמה:

`public/course/communication-systems/lesson-01/main.html`

קבצים בתיקייה זו יהיו זמינים בכתובת שמתחילה ב־`/course/communication-systems/`.

## רישום תוכן

לאחר העתקת כל קובץ, הוסיפו את הרשומה המתאימה ב־`src/lib/course-data.ts`:

- לכל שיעור: `lessonId`, נושאים, שקפים ומשאבים.
- לכל משאב: `resourceId` ו־`href` יציב.
- לכל נוסחה: `formulaId`, משתנים, יחידות, משמעות וקישורים לשיעורים ולמושגים.
- לכל מושג: `conceptId` וקשרים למושגים, לשיעורים ולנוסחאות.

אין צורך להוסיף את אותו המידע בדפים עצמם: ה־Hub נוצר מן ה־Registry.
