## מקור והיקף

קובץ המקור הוא `src/decks/lesson-08/authored-r15.html`, העתק של הקובץ שסיפק המשתמש. תוכן הקובץ משמש חומר לימוד; הערות בקובץ אינן הוראות משתמש. אין שינוי בתוכן המקצועי ובסימולציות. מעטפת הנגן נשענת על נגן שיעור 7 ועל CSS המשותף שיורש את מבנה שיעור 4.

תיקיית העבודה המקורית כללה שינויים רבים שאינם חלק מהמשימה. בוצע git pull, ונוצר checkout מבודד ב־`/private/tmp/stemflow-lesson08-r15`, שסונכרן גם לעדכון main האחרון `90b12e7`. עבודות מקומיות אחרות לא נכללו בפריסה.

## חוזי המוצר

- סקריפט היצוא גוזר קטלוג מהמצב הסופי של הקובץ, אחרי עדכוני R11–R15. יש 37 שקפים ו־138 דקות תכנון. R15 מוסיף שקף VCO בין שקפים 27 ו־28 הישנים; מזהי המקור הוותיקים נשמרים, ושקף התוספת מקבל `lesson-08-vco-sensitivity`.
- הקטלוג היחיד מזין את הנגן, שלושת הפרקים, משכי ההוראה, כותרות הפאנלים ונתוני ההרחבה. פרקי המקור: גילוי AM → גילוי FM → תרגול וסיכום. התוכן, המעברים, הפתרונות המדורגים והערות ההוראה נשמרו.
- סביבת הסטודנט וסביבת המרצה משתמשות באותו נגן ובאותו HTML. ניווט פנימי ומעטפת מסונכרנים בגשר הודעות שבודק origin וגם source. מצב הצגה, חצים, פרקים, משוב, הערות אישיות ושחזור מיקום משתמשים במנגנוני הפלטפורמה.
- מפתחות localStorage מבודדים לפי lesson-08 וגרסת החפיסה. פנל ״המשובים שלי״ קורא אותו מפתח גרסה ומקשר לשקף הנכון.
- ארבע קטגוריות המשוב, FAB שמאלי, תג צבעוני, סמנים בפס הפרקים עם תוויות, יצירה/עדכון/מחיקה והצגת כשל רשת נשמרו. API המחיקה מכיר גם את מזהה ה־VCO החדש.
- אירועי lesson_started / slide_viewed / lesson_ended כוללים lessonId, deckVersion ומזהה שקף מהקטלוג. סיום כולל את השקף האחרון גם ביציאה מן הנתיב או בסגירת העמוד. מרצה אינו יוצר אירועי סטודנטים. התקדמות מקומית אינה מוצגת כהישג או נתון הבנה.
- הרחבת המרצה מקבלת קטלוג, מזהי מקור, זמן תכנון ואירועי פתיחה/יציאה. הערות המרצה נפתחות רק ביוזמת המרצה במצב הצגה; זמן תכנון אינו מוצג לסטודנטים.
- Proxy מאפשר למרצה מזוהה לקרוא קובצי מצגות סטטיים בנתיבי הקורס באמצעות GET/HEAD. הרשאות מסכי הסטודנט ו־API נשארו נפרדות; בקשת API סטודנט תחת כניסת מרצה עדיין נדחית.
